## 简单介绍一下typescript
TypeScript 是一种由 Microsoft 开发的开源编程语言，它是 JavaScript 的超集，添加了静态类型检查和其他一些功能。TypeScript 代码最终会被编译为普通的 JavaScript 代码，因此可以在任何支持 JavaScript 的环境中运行。

## ts类型检查发生在什么时候，静态代码检查，这个静态是什么含义？
1. 编译时检查：TypeScript 代码在编译时会进行类型检查，发现类型错误并报错。
2. 静态代码检查：类型检查是在代码编写阶段进行的，而不是在运行时。这意味着类型错误可以在开发阶段就被发现，而不是在程序运行时才暴露出来。

## 编译器中的静态检查，大致是如何运行的？
1. 解析代码：编译器会将 TypeScript 代码解析为抽象语法树（AST）。
2. 类型检查：编译器会遍历 AST，对每个表达式和语句进行类型检查。它会根据类型注解、类型推断和类型规则来判断代码是否符合类型规范。
3. 报错处理：如果发现类型错误，编译器会报错并指出错误的位置。错误信息通常包括错误类型、错误位置和错误原因。
4. 生成 JavaScript 代码：如果类型检查通过，编译器会根据 AST 生成对应的 JavaScript 代码。

## 如果ts编写的类型没有问题，有没有可能在编译成js运行时出现问题？
有可能。虽然 TypeScript 是 JavaScript 的超集，但是在编译时进行类型检查只是静态检查，而不是动态检查。在运行时，仍然可能会出现类型错误导致程序崩溃。
