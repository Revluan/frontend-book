## 图片的性能优化方式
1. 选择合适的图片格式 ：根据场景选择 WebP、AVIF 等现代格式，它们比 JPEG、PNG 更小且质量更好。
2. 图片压缩 ：使用工具（如 TinyPNG、Squoosh）压缩图片，减少文件大小。
3. 响应式图片 ：使用 srcset 和 sizes 属性，根据设备提供不同尺寸的图片。
4. 懒加载 ：仅在图片进入视口时加载，减少初始加载时间。
5. CDN 加速 ：使用 CDN 分发图片，利用缓存和就近访问提高加载速度。
6. 预加载 ：对关键图片使用 preload 提示浏览器提前加载。
7. 使用 SVG ：对于图标等简单图形，SVG 体积小且可缩放。
8. 图片尺寸优化 ：提供与显示尺寸匹配的图片，避免浏览器缩放。
